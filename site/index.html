A 3D engine for the web that starts at 23,626 bytes gzipped.

A TypeScript engine with a Rust kernel compiled to WebAssembly, WebGPU rendering, an optional WebGL2 fallback, and optional packs.

Get started Open the live demo

Five lines to a rendered scene

The margoengine facade mounts a canvas, enables orbit controls and starts rendering.

import {createStage} from 'margoengine';
const app = await createStage('#scene');
const orb = app.sphere({color: '#84d6bd', roughness: 0.25});
app.onTick(delta => {orb.rotation.z += delta;});
window.addEventListener('pagehide', () => app.dispose(), {once: true});

What the core gives you

About 22 kB gzip
Core plus the stage facade, with the embedded Wasm kernel and the WebGPU backend. The build fails at 25,000 bytes gzip or above; npm run measure:size prints the current figure. The WebGL2 fallback is the optional @margoengine/webgl (3.0 kB gzip).
Transforms in Wasm memory
Hierarchy, culling and world matrices run in a Rust kernel over flat typed arrays. An engine starts with 1,024 entity slots and doubles them on demand, up to 8,388,608.
Instancing by default
Visible meshes sharing a geometry instance render in one instanced draw call per scene pass, with per-instance material values.
WebGPU first, WebGL2 fallback
Reversed float depth, GPU picking and automatic device-loss recovery on WebGPU. Basic scenes (core meshes, flat PBR, one light) also render on WebGL2 with the optional @margoengine/webgl package.
Plugins, not a monolith
Frame-graph passes and shader hooks let optional packs add features without growing the base bundle.

Optional packs

Each pack is a separate, side-effect-free package. Your bundle includes only the ones it imports.

Assets

gltf and gltf-pro for static and textured glTF, blender for prepacked .margo exports, plus loaders for STL, OBJ, PLY, 3MF and USDZ.

Rendering

environment for HDR image-based lighting, shadows, clustered lights, post for SSAO, taa, tonemap and lines.

Interaction

controls for orbit, fly and transform gizmos, selection for outlines and picking, and react for ordinary React 18 and 19 components.

Domains

creative and vfx for particles and post effects, scenery, terrain and splats.

Where it stands

Margo Engine is at version 0.1.0 and Apache-2.0 licensed. WebGPU needs a supporting browser on HTTPS or localhost. Particles, image-based lighting and the scenery pack require WebGPU. Its real-GPU test suites run in Edge (Chromium) on a Windows laptop with an Intel Arc 140V; Chrome uses the same engine. Firefox, Safari and mobile GPUs are not yet verified.

The Margo Engine whitepaper gives the design and every measured number behind this page, each with its source and hardware. The Margo Voxel whitepaper covers the voxel editor, path tracer and multiplayer packages built on it.
