Benchmark Margo on your machine

These are the same scenes and the same measuring code that npm run bench runs on our machines. Pick the suites, press Run, and your results appear next to ours. Your browser needs WebGPU. Close other tabs and plug in a laptop for steady numbers.

Each run loads the scene in a fresh frame, warms up for 60 frames, then measures CPU time per frame, GPU time per frame (WebGPU timestamp queries, when your browser allows them), frames per second and memory. The table shows the median over runs. The startup suite reuses this page's cache, so its numbers are lower than a cold start. The full tool, with the quiet-machine gate and every suite, is npm run bench in the repository (docs/benchmarking.md).
