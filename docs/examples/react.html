Use Stage in JSX

Stage configures the stage already owned by Canvas. Install the optional @margoengine/shadows peer to enable the shadows prop shown here; the animated preview keeps the WebGL fallback available.

import { Canvas, Stage, Mesh, BoxGeometry, PbrMaterial } from '@margoengine/react';

export function App() {
  return (
    <Canvas style={{ height: 400 }}>
      <Stage camera={{ position: [0, 2, 5] }} shadows>
        <Mesh position={[0, 1, 0]}>
          <BoxGeometry args={[1, 1, 1]} />
          <PbrMaterial color="#84d6bd" />
        </Mesh>
      </Stage>
    </Canvas>
  );
}

The aliases mesh, boxGeometry and meshStandardMaterial are the same components as Mesh, BoxGeometry and PbrMaterial. With import * as Margo from '@margoengine/react', use <Margo.mesh>, <Margo.boxGeometry /> and <Margo.meshStandardMaterial />. React treats bare lowercase JSX tags as DOM elements even when imported.
