# Scientific colour encodings

Batch 178 job 4 extends the existing optional `@margoengine/sciviz/colormaps` entry. Core and stage have no new imports or features.

`colorScale(source, options)` returns a Colormap. Its `domain` is in data units. Supply that same domain as the layer and colour bar `range`. `sample(t)` continues to take a linear fraction of that range; the map then applies its linear, log or symmetric-log transform. Log domains must be positive. Symmetric log uses sign(x) log(1 + abs(x)/constant), with constant 1 by default. `position(value)` returns the transformed legend coordinate. A plain Colormap retains its previous clamp/wrap behaviour.

Continuous is the default. `bins` makes 1 to 256 equal intervals in transformed coordinates. Alternatively, `boundaries` gives strictly increasing data edges including both domain endpoints. `colors` supplies one sRGB colour per bin; otherwise the source map is sampled at each interval's centre. Internal edges belong to the following interval; the upper endpoint belongs to the last. `nan`, `under` and `over` default to grey and the source endpoints. Infinities classify as under/over. These colours precede cyclic wrapping. `tolPalette` returns the author's default categorical order; `tolColormap` supplies discrete integer categories with domain [0, palette length]. Categories are never blended.

The four new names describe their constructions:

| Name | Construction |
| --- | --- |
| lab-linear-blue-yellow | CIELAB L* 25 to 90 at a constant rate, through a neutral midpoint |
| lab-diverging-blue-red | Symmetric CIELAB path with a lightness reversal smoothed at sigma 6/256 |
| lab-cyclic-diamond | Four-reference CIELAB diamond rounded by a periodic cubic B-spline, with C2 continuity |
| lab-isoluminant-hue | CIELAB L* 70, chroma 20 and hue 260 to 20 degrees, for relief shading |

Chroma is reduced at fixed lightness to stay inside sRGB; RGB clipping must not disturb the prescribed L*. These are independent constructions, not copies of any other collection or claims of identical named palettes. The cyclic spline deliberately rounds the whole diamond; it does not claim to reproduce a particular Gaussian table.

`simulateCVD(rgb, type, severity)` accepts protan, deutan or tritan deficiency, and severity 0 to 1 (default 1). It decodes sRGB, multiplies the author's row-major matrix in linear light, clips to the display gamut and encodes sRGB. `cvdMatrix` interpolates adjacent published severity tables at increments of 0.1. Simulation is a diagnostic; no claim is made that every map or every categorical pair is distinguishable under every deficiency. Pale and light Tol schemes serve labelled backgrounds rather than fine lines.

`encodingLegend(figure, entries, options)` adds size and shape keys owned by the figure. Entries have text, CSS colour, shape and optional diameter/side length in CSS pixels. Shapes are line, dot, square, triangle, diamond, cross and hexagon. Sizes must be positive and at most 256 px. These are explicit legend keys for the consuming layer; the function does not invent a data-to-size formula or add scatter glyph shapes. Current native scatters use round/square marks. The HTML box, raster and SVG polygons/circles share their geometry; PDF consumes that SVG. Disposal removes the legend and figure disposal removes its publication root.

## Renderer and export contract

CPU-coloured lines, scatters, heatmaps and categorical meshes classify exceptional values before lookup. Explicit missing-data colours keep heatmap cells present; ordinary heatmaps retain their previous NaN holes. Surface holes remain holes because NaN heights have no geometric location. GPU surfaces, grid meshes, graph nodes, LIC, ordinary volumes and slices share one lookup routine. Opted-in maps use a 256 x 4 rgba32float texture (16,384 bytes) containing the source ramp, immutable scale metadata, transformed bin edges, special colours and category colours. Bin selection and scalar transforms happen in the shader, rather than filtering a sampled boundary. Continuous lookup interpolates 256 source samples in linear light. No float32-filterable extension is needed. Plain maps retain their 256 x 1 sRGB8 texture (1,024 bytes). Ordinary volume transfer ramps retain hardware filtering; float-table lookup is compiled only for explicit colour scales. Pipeline keys distinguish those layouts, including mixed volumes in one figure. A medical state reconstruction regression exposed precision instability when ordinary volume filtering was unnecessarily replaced; retaining its original filtering restores exact pixels.

Volume upload preserves runtime NaNs and finite values outside the range. MIP uses an explicit first-finite-sample state, so negative maxima are not replaced with zero. Explicit gradient/preintegrated classifiers continue to own their full two-dimensional transfer function; a colour scale does not replace those classifier definitions. Volume opacity remains its transfer curve; special samples have alpha one before density/compositing. The source classifier snapshot remains the existing 256-entry opacity table for conservative volume-quality bounds.

Colour bars use transformed tick positions and exactly repeated gradient offsets at bin boundaries. HTML, PNG, tiled media and SVG share those stops. PDF stitching creates only positive-width domains, with independent endpoint colours at a discontinuity. It never approximates a hard edge with a tiny ramp. Figure state retains the scale recipe, bin edges and special colours alongside the existing sampled source table.

## Evidence and reproduction

`color-scales.test.js` checks prescribed CIELAB lightness, symmetric divergence, cyclic seam derivatives, exact Tol rows, author CVD matrices, identity/severity interpolation, every map under every deficiency at all eleven tabulated severities, scale validation, exact bin stops, legend polygons and portable scale recipes. `pdf.test.js` retains a regression for equal-offset SVG stops and nonempty PDF stitching domains.

`colors-browser.mjs` renders 20 maps at 16 scalar probes on native WebGPU and the WebGL2 compatibility device. The probes include NaN, infinities, range endpoints and internal bin edges. The fixed comparison bound is 0.012 encoded sRGB per channel, including 8-bit target quantization and the existing 256-entry continuous table. Observed maximum on both backends: 0.008482728. Mixed plain/encoded slices reuse one figure without binding conflicts; an all-negative MIP verifies first-finite maximum selection. Four actual mapped volume slices produce identical backend centre pixels: under red [255,0,0], NaN magenta [255,0,255], midpoint grey [99,99,99] and over green [0,255,0]. The OISST demo renders all 228 retained cells and the stellar panel displays 20,000 of the existing 2MASS records; PNG, SVG, PDF and figure-owned legend cleanup are checked. Records and captures are in test-results/sciviz-colors; the compact result is retained in whitepaper/results/batch178-colors.json.

Run the normal package build first, then the sciviz CPU tests and `node scripts/gpu-lock.mjs run --owner=colors --wait-max=60 --max=5 -- node packages/sciviz/tests/colors-browser.mjs`. This is a correctness test, with a shared GPU slot and no timing assertion. The wider package GPU evidence covers surfaces, volumes, graph/grids/LIC, restoration, transfer classifiers, depth, conservative volume bounds, derived fields, state reconstruction, media capture and PDF publication. No speed result is claimed.

## Clean-room basis

- Peter Kovesi, **Good Colour Maps: How to Design Them** (2015), https://arxiv.org/html/1509.03700. Compared its lightness-rate, symmetry, cyclic reference-region and relief-shading constructions. Combined constant-lightness gamut handling with its construction constraints; diverging smoothing uses the paper's recommended 5 to 7 samples. No companion code or colour collection was read.
- Carl de Boor, **On Calculating with B-Splines** (1972), Journal of Approximation Theory 6, 50-62, https://doi.org/10.1016/0021-9045(72)90080-9, primary paper https://www.stat.uchicago.edu/~lekheng/courses/302/classics/deboor.pdf. Periodic cubic basis weights supply analytic seam continuity rather than a finite sampled convolution with residual kinks.
- Paul Tol, **Colour schemes and templates**, qualitative colour definitions updated 16 August 2026, https://sronpersonalpages.nl/~pault/. Eight categorical schemes are numerical definitions transcribed from the author page, not an implementation. Their intended roles and exact ordering are retained.
- Gustavo M. Machado, Manuel M. Oliveira and Leandro A. F. Fernandes, **A Physiologically-based Model for Simulation of Color Vision Deficiency** (2009), IEEE TVCG 15(6), 1291-1298, https://doi.org/10.1109/TVCG.2009.113. Corrected author paper: https://profs.ic.uff.br/~laffernandes/content/publications/journal/2009_tvcg_15%286%29/machado_oliveira_fernandes-tvcg-15%286%29-2009-corrected.pdf. The author supplement's numerical Table 1 and stated interpolation rule are at https://www.inf.ufrgs.br/~oliveira/pubs_files/CVD_Simulation/CVD_Simulation.html. Only the paper and numerical tables were used.
- W3C SVG Working Group, **Scalable Vector Graphics 2, Paint Servers, Notes on gradient stops** (2018), https://www.w3.org/TR/SVG2/pservers.html#StopNotes; Adobe Systems, **PDF 32000-1:2008**, section 7.10.4 stitching functions, https://opensource.adobe.com/dc-acrobat-sdk-docs/pdfstandards/PDF32000_2008.pdf. Repeated SVG stop offsets are represented by distinct positive PDF domains, not repeated bounds.
- W3C GPU for the Web Working Group, **WebGPU Shading Language** (2026), https://www.w3.org/TR/WGSL/. NaN values arrive as runtime data; constant evaluation may not construct nonfinite floats. This informs volume packing and MIP state without changing core.

Existing unmodified NOAA and 2MASS assets retain their source/license/hash records in examples/assets/sciviz/contour2d/source.json and examples/assets/sciviz/stars.json. No new external implementation, engine dependency or registry package is included.
