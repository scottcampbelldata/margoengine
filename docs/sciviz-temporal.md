# Temporal analysis

`@margoengine/sciviz/temporal` is an optional CPU entry with lazy spatial probing and native Figure chart layers. It adds no import to core, stage or the sciviz root. `TemporalSource<T>` pairs strictly increasing finite times with `read(index, {signal})`. A reader may reuse its buffer after the next read; each operation owns its returned arrays. Reads are sequential and failures preserve their original error. Long reductions yield for cooperative cancellation.

`temporalStatistics(source, options)` returns per-element mean, minimum, maximum, standard deviation and valid count over the half-open `[start, stop)` step range. Defaults select every step with equal weight, omit NaN and use population standard deviation (`ddof: 0`). `ddof: 1` gives sample standard deviation. Missing policies also include `propagate` and `error`; infinity always rejects. No observations, or insufficient observations for the chosen deviation, produce NaN. A shifted Welford recurrence avoids subtracting large sums of squares. Field storage is O(field length), plus an O(step count) time-axis snapshot, with one read per selected frame and no retained field history. Frame widths must match; correspondence of tuples across steps belongs to the reader. Changing geometry can be sampled first with a fixed physical probe.

`interpolateTemporal(source, time, options)` supports `linear` (default), `step` and `nearest`, including irregular intervals. Exact keys read only that frame; nearest ties select the earlier key. Outside times reject unless `outside: 'clamp'` is explicit. Linear interpolation retains missing endpoint values as NaN. It creates an owned float64 field, so seeking backwards never modifies earlier results. There is no hidden frame cache or automatic extrapolation.

`probeTemporal(gridSource, xyz, options)` loads `/probe` lazily and samples the same physical position in every regular, curvilinear or unstructured frame. Select a named field, point/cell association and vector component; defaults select unnamed point scalar component zero. A position outside a frame has `valid=0` and NaN. Absent requested fields in an intersecting frame reject. `plotTemporalProbe(figure, probe, options)` draws contiguous valid runs as lines and isolated observations as scatter marks. Missing steps create gaps. The chart rebases x by its returned `origin`, default first time, to preserve sub-step detail when Figure uploads float32 coordinates. Label the x axis in those relative units. The chart owns its layers, supports `Symbol.dispose`, and rolls back its own additions on failure or abort. Dispose it before its figure.

`groupFileSeries(names, options)` groups the final digit run in a basename, keeping directories and suffixes distinct. Leading zeros are allowed. Times are `start + (number - firstNumber) * step`, preserving missing-number gaps; defaults are start 0 and step 1. An unnumbered file forms its own group. `parseFileSeries(json, options)` accepts ParaView's version 1.0 `.series` JSON with explicit `name` and numeric `time`, sorts steps and rejects duplicate times/names. An explicit `baseURL` resolves relative names. Default units are seconds. `fileSeriesSource(series, loader)` adapts any existing reader, passes cancellation through, checks indices and stores no payloads. Series metadata is frozen.

`parseTimeUnits`, `convertTimeUnits` and `formatTemporalTime` support microseconds, milliseconds, seconds, minutes, hours, days and weeks, including common abbreviations. A unit may have `since YYYY-MM-DD` plus time and UTC offset. Origins use the proleptic Gregorian calendar, UTC when no offset is supplied, and millisecond precision. Conversion cannot silently mix relative durations and absolute axes. NaN coordinates survive conversion; infinities and numeric overflow reject. Calendar months, years and leap seconds are unsupported. Model-calendar decoding belongs to the separate `/cf` capability; temporal algorithms also accept already decoded numeric model times without any wall-clock origin.

The real-data page is `examples/sciviz-temporal.html`. It displays all four reductions, an interpolated spatial field and a selectable physical probe chart on NOAA daily wind and ERA5 temperature sampled every six hours. `examples/assets/sciviz/temporal/source.json` records licences, transformations and SHA-256. Six-hour sampling is labelled explicitly, not presented as observed hourly values. Data remain in their physical m/s or K units.

Evidence: `packages/sciviz/tests/temporal.test.js` independently checks large-offset variance, two-pass reference reductions on real fields, irregular times, buffer reuse, missingness, cancellation, moving grids, vector/cell probes, file naming, JSON series and unit origins. `packages/sciviz/tests/temporal-browser.mjs` renders the real fields and probe charts on WebGPU and full WebGL2, checks all four reductions, gap splitting, rollback, disposal and exact device-reboot pixels. No speed claim is made.
