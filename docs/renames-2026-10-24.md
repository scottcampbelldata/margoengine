# Public API changes, 2026-10-24

Codex's `work/changes` engine work (Studio integration, multi-view, voxel, lightmap, exporters) landed on `main` after a
review and rewrite. Names below that never reached `main` were only on that branch; apps that vendored a build of it
(Voxel Studio, Margo Mesh, MargoTile) update their imports from this list. No old names are kept.

## Core and the stage facade (multi-view, scenes, layers)

| Before | Now |
| --- | --- |
| `RenderView.mask` | `RenderView.layers` |
| `PassContext.view.mask` | `PassContext.view.layers` (the view record also has `count` and `clear`) |
| `PassContext.viewIndex` | `PassContext.view.index` |
| `PassContext.viewClear` | `PassContext.view.clear` |
| `engine.render({viewport, pixels, scissor, clear, mask, id})` | `engine.render({views: [{camera, viewport, pixels, scissor, clear, layers, id}]})` |
| `Mesh.layer` | `setRenderLayers(mesh, mask)` from `@margoengine/cameras/layers` (one layer concept) |
| `SceneView` | `RenderView` |
| `rectangleClear` | removed from the public API (core clears partial views itself) |
| `RenderView.target` colour must be the canvas format, 1 sample | any renderable colour format; a 4x MSAA view draws into core's own 4x textures, resolves colour into the target and writes the nearest depth sample into a 1x target depth |
| – | new `PassContext.view.target` (the view's target textures; absent for the canvas) |
| `Scene` (value export) | `Scene` is a type; create scenes with `engine.createScene(name)` |

## Cameras

**Behaviour change:** `getCameraLayers(camera)` now defaults to every layer (it was layer 0), so a mesh moved to
layer 2 with `setRenderLayers` stays visible until a camera or view is given a mask. Core draws layers per view; nothing
is hidden by toggling `mesh.visible` any more.

| Before | Now |
| --- | --- |
| `CameraLayers` plugin | `setCameraLayers(engine.camera, mask)`; core draws each view with its `layers`, else its camera's mask |
| `renderView(engine, options)`, `RenderViewOptions` | `engine.render({views: [{camera, layers}]})` |
| `SceneSwitch` | core scenes (`engine.createScene`, a view's `scene`) or layer masks |
| `getCameraLayers(camera)` default 1 (layer 0) | default every layer (`ALL_LAYERS`) |
| `CameraProjection` throws `Error` | throws `MargoError` (`state`, `attached`); new getter `fixedOrthographic` |

## Labels, post, controls

| Before | Now |
| --- | --- |
| `LabelRenderer.view` | `view: {camera, viewport, pixels?}` option |
| `projectIntoView` (labels) | removed; labels project inside their view |
| `MaterialClear(device, formats, extra)` | `MaterialClear(formats, extra)` |
| `TransformControls` `view: {camera, viewport}` in CSS pixels | `view: RenderView` (viewport in canvas fractions unless `pixels: true`) |
| decal value overflowing float32: `RangeError` | `TypeError` |
| environment `withCaptureLayers` | removed (captures read `@margoengine/cameras/layers`) |

## Math

`Quaternion.normalize` now returns a unit quaternion for very large or very small inputs (it returned zeros or the
identity); ordinary inputs are unchanged.

New in `@margoengine/math/quat`: `rotationToQuaternion`, `axisAngleToQuaternion`, `conjugateQuaternion`,
`normalizeQuaternion`, `rotateByQuaternion`. Every package that converted matrices to quaternions uses them.

## Lightmap and BVH

| Before | Now |
| --- | --- |
| `bakeLightmap({areaLights, bounces, bounceRays, emissiveLights, transmission, glassVolumes, lightingAsset})` | `bakeGlobalLightmap(...)` from `@margoengine/lightmap/global` |
| `AreaLight {corner, edgeU, edgeV, radiance, samples}` | clustered `RectAreaLight` plus the `areaSamples` option |
| `LightmapGlassVolume.transmission` | `factor` |
| refracted directional emitter | `{type: 'directional', direction, color, intensity, aperture: {corner, edgeU, edgeV}}` |
| refracted point emitter | a `BakeLight` point (power 4π × color × intensity) |
| refracted area emitter | `RectAreaLight & {type: 'area'}` |
| `RefractedDirectionalEmitter`, `RefractedPointEmitter`, `RefractedAreaEmitter`, `finishLighting`, `finishRequest`, `RefractedDiagnostics.reservedRays/reservedBytes` | removed |
| bvh `finiteShadows: 'biased' \| 'segment'` | `segmentShadows: boolean`; `SegmentOptions` = `Pick<RaycastOptions, 'side' \| 'includeFace'>` |
| `bakeVertexColors`, `limitPalette`, `BakeAmbientOcclusion`, `BakeLight`, `BakeOptions`, `BakeTarget`, `PaletteMode` from `@margoengine/bvh` | from `@margoengine/bvh/bake` (the raycasting root no longer carries the baker) |
| `lightingAsset` from `@margoengine/lightmap/global` | from `@margoengine/lightmap` |

## Exporters
