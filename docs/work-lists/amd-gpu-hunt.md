# AMD GPU bug hunt (work list 5, batch R6)

Every package GPU and browser test (`npm run check:gpu-packages` plan, one package per run, `--serial`) on the
project's only AMD GPU, on WebGPU and on the WebGL2 compatibility layer (`MARGO_COMPAT=1`), to find what NVIDIA never
shows. Scott, 2026-11-10.

- Machine: Beelink, AMD Radeon 680M (RDNA 2 iGPU, device 0x1681), driver 32.0.21030.2001, Windows 11, Chromium
  through Playwright (WebGPU on Dawn D3D12; WebGL2 on ANGLE D3D11).
- Profile: `MARGO_MACHINE_PROFILE=mini-pc` with the machine's temperature logger (`MARGO_THERMAL_FILE`), one GPU slot
  (`MARGO_GPU_SLOTS=1`), the GPU held in chunks of about 25 minutes so the other stream's runs can queue.
- Base: origin/main `ab36011e0` for the sweep. Reruns of every failed suite on current main after the fixes:
  `8b72f1dae` and `391011efa` (WebGPU), `17eebeb5c` (the WebGL2 layer, headless, rivers), with
  `MARGO_ENGINE_BENCH` set for the fixtures. No failure here was only about time, so busy-retests.md has no new row.
- Not run here: `voxel-pathtracer` (excluded by the mini-pc profile: it froze this machine once; it runs on the
  workstation profile only). Speed-deferred suites are listed by `scripts/speed-phase.json` and are not part of this sweep.

Status: fixed (commit), known-bugs (entry), time-only (busy-retests.md), or open. Rows 28 on came from the WebGL2
layer sweep (their first commit seen is the sweep base).
