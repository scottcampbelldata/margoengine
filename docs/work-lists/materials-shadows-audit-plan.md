How to read this plan:

- CONFIRMED means a CPU script reproduced it on the built `dist` (the real `Engine` on a fake renderer and the recording
  fake device of `examples/package-benchmarks/proofs/gpu-recorder.js`, no GPU). The quoted line is the script's output.
  SUSPECTED means the code path was read end to end but not run, or needs a GPU to show.
- The scripts were kept outside the repository and are not part of this change.
- Byte figures marked "measured" come from a text replacement on the built `dist` files, each compressed with gzip
  level 9 before and after. They are per-file sums. Every item must be measured again with the real size script when it
  is built. "Estimated" figures were not built.
- Every fix lands with the regression test named in its row, which must fail without the fix.
- Rows already in `docs/known-bugs.md` or the bug-sweep list are left out. Two that are still visible are named in
  section 4.

## Suggested order

1. **B1** and **B3**: wrong pictures with default settings, both small, both with CPU tests.
2. **B2** with **B12**, together with core row B10, since they share the cause.
3. **B4**, **B5**, **B6**: three frame-loop stoppers and a stale cache, each with its script already written.
4. **S1** (usage numbers): the largest measured saving with the least risk, and room for the fixes above.
5. **A1**, **A2** and **B7**: input checks, cheap.
6. **B8** and **B9** (variance filter and the lower device levels), with their GPU tests.
7. **B10**, **B11**, then B13 to B16 as each is reproduced.
8. **A3** to **A11**, with rulings where the row says so. **S2** to **S5** last.

## Do not do

- Do not change core for any row here; B2 has a package fix that stands without core row B10.
- Do not loosen a picture budget or a tolerance to land B3 or B8: the cascades' pictures must not move with B3, and B8
  changes only maps smaller than the depth map.
- Do not rename WGSL names that other packages patch (`shadowLit`, `shadowFrame`, `shadowMap`, the `shadowFx` prefix).
- Do not merge the `Shadows` and `VirtualShadows` entries to save the duplicate text of S2; move only the shared checks.
- Do not build S5 unless its bytes are paid for by S1.
- Do not raise an entry ceiling for a fix before S1 is measured with the real size script.
