How to read this plan:

- CONFIRMED means a CPU script reproduced it on the built `dist` (real `Engine`, `FrameGraph`, `GPURenderer` and
  `CADCameraControls` on fake renderers and devices, no GPU). The quoted line is the script's output. SUSPECTED means the
  code path was read end to end but not run.
- Byte figures marked "measured" come from a copy of the core, stage and shared sources built with the real steps
  (`tsc`, `scripts/compact-package.js`, then the `measure-size.js` bundle settings). That copy measures core at 22,225 B
  (the official figure exactly) and core + stage at 24,747 B (78 B under the official 24,825 B, a stage build step the
  copy does not run), so the deltas are sound and the totals are not official. Every item must be measured again with
  `npm run measure:size` when it is built. "Estimated" figures were not built.
- Core alone sits 1 B under its own ceiling. A core fix that adds bytes needs a saving from table 2 in the same landing,
  or Scott's yes to raise `CORE_ONLY_CEILING`.
- Every fix lands with the regression test named in its row, which must fail without the fix.
- A stage helper is adding the `createStage` background option now (about +23 B). Nothing below touches that code.

## Suggested order

1. **S1** (usage numbers, -115 B core): the largest saving with the least risk, and it gives core the room every fix
