The only descriptor edit removes `fragment.targets[0].blend` from the exact particle HDR render pipeline. The hook checks `rgba16float`, sample count one, original alpha blend factors, both vertex/fragment entry points, reverse-depth comparison and disabled depth writes. It checks live buffers: 224-byte uniform, two separate 64-byte-per-particle states, 4-byte-per-particle shared alive IDs, 20-byte shared indirect arguments and 8-byte shared respawn counters. Compute groups reverse source/destination state; draw groups read each state through STORAGE, sharing the alive list. State and alive buffers have no VERTEX usage. The current source's one-state implementation is intentionally rejected by this pinned-live probe.
