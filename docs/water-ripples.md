# Local interactive water ripples

Batch 235 job 1 adds `@margoengine/water/ripples`. Attach Ripples after a live Water in the same engine. `disturb(x,z,radius,strength)` queues a drop; `wake(previousXZ,currentXZ,radius,strength)` queues the swept object footprint. Boats and characters supply their previous/current world position. Signed strengths support entering and leaving water. No physics dependency is required.

The GPU owns height and vertical velocity. A five-point wave stencil uses semi-implicit integration and a CFL step no larger than 0.45 cell widths / speed or 1/120 second. Velocity damping is exponential. An eight-cell absorbing strip damps outgoing waves. Circular impulses use the compact profile `(1-q)^2(1-4q)` for squared normalized radius q below one; its continuous circular integral is zero. Capsule footprints sweep this profile along the object path. Camera following shifts in whole cells; overlap retains old world positions and new cells start at zero. A stable GPU buffer supplies displacement, normals, caustic surface capture and WaveQuery height/normal/vertical velocity. Rendering has no CPU field readback.

Defaults: 64 m square, 128 cells per axis, speed 3 m/s, damping 0.6/s, camera following enabled. Size 1..10000 m; resolution integer 16..512; speed 0.01..100 m/s; damping 0..100/s. Radius spans one cell to half the map; strength is -100..100 m. At most 64 queued events per update; overflow rejects atomically. A stall advances at most 0.25 s; configurations needing over 512 stable substeps reject. One field follows the first drawn camera each engine update; other views share it. These constant-speed height-field disturbances supplement coastal flow and do not overturn or claim dispersive ocean accuracy or automatic rigid-body coupling. Restore resets the field, disposal releases resources and registration, and readFrame supports AbortSignal.

The parity row covers interactive height fields for boats, characters and drops: circle and swept object disturbances, propagation, interference, camera movement, displacement and normals are present. The existing named water addons provide flow and planar optics; this entry adds interactive disturbances. No rival source was read. The demonstration wake uses the real NOAA NDBC 46042 observation attributed in packages/water/test/data/README.md, public-domain US government data. Its wind bearing sets an authored example wake direction, not an observed boat track.

Proof: packages/water/test/ripples.browser.mjs checks an independent JavaScript stencil and analytic impulse, flat initialization, swept wake, WaveQuery height/vertical velocity, exact overlap retention, teleport reset, restoration and GPU validation on both backends. CPU tests cover validation, bounded queue, disposal and cancellation. Reproduction is in docs/whitepaper/reproduce.md. No timing claim is made.
