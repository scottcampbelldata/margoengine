
## Shared scientific selections

The optional @margoengine/sciviz/link entry exports SelectionStore, selectionOperation and bindSelection. A store owns unique string or finite-number dataset row keys. Bind a scatter, line, histogram, bar or heatmap layer in any figure with its rowIds, or with groups of dataset keys for aggregate marks. Numeric and string identities stay distinct, and reordered subsets retain their dataset identity. Dispose a binding before replacing its layer. A binding requires WebGPU or the WebGL2 compatibility device; native WebGL2 is outside this entry.

SelectionStore.select accepts row keys and a source brush identity. The default operation replaces that brush. Other operations are union, intersect, toggle and subtract. The default resolve is global: a new view brush replaces the previous view brush. Union keeps one brush per view and accepts membership in any brush. Intersect accepts membership in every active brush. Bindings without an explicit source share an automatically assigned source within one figure. Within a figure/source, all bound scatter and line hits merge before publication. Missing brushes contribute no constraint. An explicit empty brush rejects every row. clear removes a brush or all brushes. With no brushes, empty defaults to true; empty:false rejects all rows. Undo and redo restore all view brushes, with 32 historical edits by default; history:0 disables undo.

The change event carries source, active, version and a lazily computed rowIds snapshot in dataset order. subscribe returns an unsubscribe function and accepts AbortSignal. Shift toggles, Ctrl or Meta adds, and Alt intersects. Figure box/lasso selection drives bound scatter and line brushes. Clicking an aggregate rectangle selects its source rows. Undo is available programmatically and in the stars example. Synchronous mutations validate every key before changing state. Symbol.dispose and dispose release stores and bindings; a binding restores the original layer visibility.

Display mode defaults to fade with unselected brightness 0.12. highlight tints selected marks amber; filter discards unselected marks. Filtered histograms scale each bin height by selected membership. Bar and heatmap filters retain their full geometry. Aggregate masks contain selected member fractions. The mask is one f32 per mark, aligned to 16 bytes with a 16-byte minimum. A selection writes each nonempty layer mask once. Geometry and colours remain on the device. Masks, geometry and bindings rebuild from current CPU state on device restoration. The baseline marker renderer handles round scatter points, connected line segments and filled rectangles; advanced point effects and line joins are follow-up presentation work.

The stars example links the existing one-million-source public-domain 2MASS sample to a histogram and colour against magnitude heatmap. Click a bin or brush the sky view to operate on the same source keys. The sample's quality cuts and selection bias are recorded beside the asset. The correctness stress test renders two copies of those observations to exercise two million plotted marks. This is a work-count proof, not a timing claim.
