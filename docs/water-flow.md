# Flow-map water

The optional water/flow entry exports WaterFlow and WaterFlowOptions. Attach after Water, with a map provider returning a painted or generated linear texture. RG decodes from [0,1] to [-1,1] by default; signed:true accepts direct signed vectors. Providers are re-read every draw. Omitted/loading maps use a generated uniform direction texture. RGB normal maps use RGBA storage; two providers can supply independently authored normal detail. When both are ready their tangent-space slopes blend; otherwise both phases use continuous analytic gradient noise.

Defaults: origin [-50,-50], size [100,100] metres, direction [1,0], speed 1 m/s, tileSize 4 m, period 4 s, strength 0.12. Size is positive, direction components -1..1, speed 0..100, tileSize 0.01..10000, period 0.01..1000, strength 0..10. setTime uses finite 0..1e9 seconds. Zero vectors/speed suppress detail, and outside the world rectangle the flow contribution is zero. Water geometry, coastal physics, absorption and reflection retain their existing owners. Flow detail replaces wind micro-detail and preserves ripple displacement and normals.

Two triangle-weighted layers are half a phase apart. Each layer resets while its weight is zero. Spatial phase noise and a different offset in the second layer reduce synchronized pulsing/repetition. Flow magnitude scales detail; screen footprints fade unresolved normal detail. Manual bilinear sampling supports float-generated fields without requiring float filtering. Accepted flow formats: rg8unorm, rg16float, rg32float, rgba8unorm, rgba16float, rgba32float. Normal maps require RGBA from that list. All textures must be single-layer sampleable 2D, sample count one, with linear colour values. Borrowed textures stay caller-owned; owned fallbacks and uniforms are released on disposal and recreated on restore. Use one WaterFlow per Water.

The parity row is flow-texture-directed river surfaces, including local direction and speed, authored/procedural normals, phase blending, configurable repeat and existing water optics. No rival code is imported. GPU checks compare flow vectors and phase-weighted slopes with an independent calculation, test phase boundaries, exact fixed-time images, visible animation and simultaneous ripple queries. The authored demonstration direction uses the real public-domain NOAA observation already attributed beside water/test/data; this is not a measured river current. Research citations are in docs/clean-room.md. No performance claim is made.
