# The Curve Lab

Exhibit 49 of Margo Web Demos places four spline families on one illuminated drafting instrument. The seven points stay in place as the basis changes. Move the blue probe along the front ruler to find the nearest point in three dimensions. Move the frame separately along the curve’s arc length. The red, mint and violet arrows show the tangent, normal and binormal. The overhead view makes each control layout easier to compare.

The bevelled casing, feet, ruler, enamel grid, pin stems, probe and markers are original parametric models. The curve and dotted control polygon are round 3D strokes generated by Margo’s TubePainter. The model is in meters and the working deck is approximately 0.64 m wide. The original design references brass tracing instruments and the clear markings on historic drafting tools.

## Four bases

| Family | How it uses the points | Arc length of this study |
| --- | --- | ---: |
| Catmull–Rom | Uniform Catmull–Rom passes through all seven points. | 1,079.4 mm |
| Bézier | Two cubic spans share the middle anchor. Four smaller pins guide the spans and the three large anchors are interpolated. | 724.2 mm |
| Hermite | The curve interpolates all seven points with the tangent directions marked by short copper rods. | 1,117.8 mm |
| B-spline | The uniform cubic basis interpolates the endpoints and uses the five inner pins as guides. | 814.0 mm |

The four kinds are built with the public Spline API. A 1,536-division arc-length table maps parameter values to approximate distances and back. The nearest-point solver isolates the stationary points of the squared distance on cubic spans and also tests their limits. The displayed gap is the Euclidean distance from the probe to the nearest point, and the station is the distance along the selected curve from its start. SplineFrames uses the rotation-minimizing method with 256 samples. The two arbitrary Bézier spans meet at a common point and have different tangents there. Each basis remains available at both limits of the frame control.

## Verification

The pinned public checkout is 0efd9cff8230507a32deb49907ecd499d46925f5. The feature packages are splines and lines. Margo Core renders the same modeled scene and geometry through its native WebGPU and automatic WebGL2 preview paths. The scene has no external runtime assets.

QA checked all families’ knots or cubic basis values, compared arc length against an independent 65,536-chord sum, checked nearest points from seven probes per family against an 8,193-point search and checked 129 frames per family for position, orthonormality and right-handedness. The largest arc-length difference was 0.0041 mm. The largest gap versus the sampled closest-point reference was under 4.3 × 10⁻⁸ m. The maximum frame orthonormality or position residual was under 4.5 × 10⁻¹⁶.

Browser checks covered the actual first type change, all four rendered shapes, both sliders, independent frame/probe motion, overhead and perspective views, and correspondences between the UI and the spline measurements. The phone profile used a 390 × 844 Chrome viewport, a disabled cache, 150 ms latency, 1.6 Mbps download and fourfold CPU throttling.
