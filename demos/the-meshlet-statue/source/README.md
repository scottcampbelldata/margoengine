# The Meshlet Statue

*Meridian* is an original bronze sculpture made from five closed, corrugated ribbons. The same indexed 172,848-triangle sculpture and gallery appear on phones and desktops. A real sliding slate wall can expose or hide its surfaces.

- A module worker constructs the indexed sculpture. The pinned `@margoengine/culling/meshlets` entry partitions this single mesh and keeps the clusters that can contribute to a view. The sculpture sits on turned stone and bronze footings in an original gallery. The moving wall and core sculpture mount are three-dimensional scene elements. Both renderer paths open with the live lit sculpture and working wall, then add the same directional shadow map after the first interaction or a brief idle interval.
- **Drawn** is Margo’s live `MeshletMesh.readTriangles()` value for the main sculpture pass. **Triangles** is the original index count divided by three. **Meshlets** is the number of source clusters reported by Margo. Main-pass counts exclude the gallery, pearl and shadows.
- WebGPU uses frustum, normal-cone and Hi-Z tests. With the wall at a fixed position, toggle **Use wall for Hi-Z** to add or remove only its depth from the engine’s occlusion input. The wall itself continues to render. Self-occlusion remains active as generated by Margo’s own previous-cluster depth pass. The count can change while the visible image stays the same.
- Margo’s current WebGL2 compatibility route uses frustum and normal-cone tests and reads the CPU submission count. Its Hi-Z switch is disabled. The wall still moves and occludes the same geometry through the regular depth test. Request that route directly with `?backend=webgl2`.

## Sources

- Ned Greene, Michael Kass and Gavin Miller. *Hierarchical Z-Buffer Visibility* (1993). Establishes the depth hierarchy behind conservative occlusion tests. [SIGGRAPH paper](https://www.cs.princeton.edu/courses/archive/spr01/cs598b/papers/greene93.pdf)
- Ulrich Haar and Sebastian Aaltonen. *GPU-Driven Rendering Pipelines* (2015). Describes clustered geometry visibility and a two-pass depth approach. [SIGGRAPH course](https://advances.realtimerendering.com/s2015/aaltonenhaar_siggraph2015_combined_final_footer_220dpi.pdf)
- Brian Karis, Rune Stubbe and Graham Thomas. *A Deep Dive into Nanite Virtualized Geometry* (2021). Discusses GPU cluster processing and conservative visibility. [SIGGRAPH presentation](https://www.youtube.com/watch?v=eviSykqSUUw)
- Guggenheim Museum Bilbao. *The Matter of Time*, Richard Serra (2005). Display reference for the relationship between monumental curved forms and movement in a gallery. The sculpture, gallery and scene materials here were authored independently. [Collection page](https://www.guggenheim-bilbao.eus/en/the-collection/works/the-matter-of-time)
