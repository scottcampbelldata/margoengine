# The Measuring Room

Inspect an original machining gauge. The width shortcut dimensions the exact end-plane separation. For custom measurements, pick two visible points for distance, two planar faces for the angle between their planes, or a bore wall or rim for true cylinder radius. Distance selections snap to nearby corners and feature edges. Drag to change the view while the leader anchors stay in the model.

The public Margo B-rep package builds, validates and tessellates the solid. The topological face groups drive scene selection, the machinery metrology entry snaps to exact displayed features and evaluates anchor distances, and Margo labels project each leader and point. Both render paths show the same faces, measurements and annotations.

References: [ISO 14405-1:2025, Geometrical Product Specifications](https://www.iso.org/standard/14405-1) and [Open CASCADE Technology, Modeling Data](https://www.occt3d.com/dev/doc/overview/html/occt_user_guides__modeling_data.html). These inform feature and measurement terminology. This is an interactive reference exhibit.
