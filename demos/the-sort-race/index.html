What the clocks measure

Both sides get the exact same million unsigned integers. The two sorts run in sequence so they don’t compete for processor time. The Margo time runs from sort submission through completion and can include first-use shader setup. Upload, readback and verification are separate. The worker measures its built-in typed-array sort directly.

The plots follow 2,048 sampled keys to their verified ranks. The verification checks all one million. Browser elapsed times depend on this device and this run.
