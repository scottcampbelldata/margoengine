# The Flood Table

The terrain, village, and hydraulic hardware are original procedural Margo meshes. The same Margo Flood solver and Water surface run on phones and desktops. WebGL2 uses Margo's WebGPU compatibility layer for those same packages. Pick a wall location, release the sluice, and reset to compare a different location. The village gauge samples the surrounding floodplain.
