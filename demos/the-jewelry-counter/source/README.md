# The Jewelry Counter

Host the built folder on HTTPS with its assets and source folders intact. The jewel is rendered in Margo. It uses refraction between generated facet planes and separate red, green and blue indices. The reference lighting uses generated studio softboxes and their reflections. The shader is a visual optics study with idealized lights and a bounded ray depth.

- [GIA round brilliant cut proportions and grading](https://www.gia.edu/dam/jcr%3Acd8270d3-bb1a-4cb9-9a2a-b95655c64a80/A-Foundation-for-Grading-the-Overall-Cut-Quality-of-Round-Brilliant-Cut-Diamonds-v2.pdf)
- [GIA appearance and fire research](https://www.gia.edu/dam/migrated-assets/docs/doc1/modeling-the-appearance-of-the-round-brilliant-cut-diamond.pdf)
- [Margo Engine public main](https://github.com/scottcampbelldata/margoengine/tree/a0eecf76a948269ead4279a31559abab1bf292b0)

The finish selector changes the live metal material. Drag or use the arrow keys to orbit. Macro centers the setting and the light control rotates both the studio reflections and the light on the gem.

The shoulder seats and structural setting follow [GIA bead-setting guidance](https://www.gia.edu/gia-website/quality-assurance-benchmark/bead-setting-diamonds-in-a-platinum-ring-shank). Studio lighting follows the mix of broad and directional sources in [GIA jewelry photography guidance](https://www.gia.edu/gem-photography).

The geometry, studio lighting and finish textures come from original code in the source folder.
