# The Stroboscope

A steady reference view shows a rotor with six identical sectors. The sampled view holds the exact phase at each selected sampling instant. Changing the sampling rate can make the same rotor seem to crawl forward, spin backward or stop. The lighting stays constant.

At a true rate of 120 rpm, 12 identical features pass the same spot each second. At 12 samples per second the sampled picture repeats. At 14 samples per second the nearest-feature interpretation moves backward at 20 rpm. The signed apparent speed subtracts the nearest integer multiple of the sampling rate from the feature frequency, then converts features per second back to rotor rpm. At the exact half-sample boundary either direction is equally short, and the readout uses the negative branch.
