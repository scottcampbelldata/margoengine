# The Capstan

The load end pulls with 150 N. As the contact angle grows, friction along the drum carries more of the load and the minimum force needed on the holding end falls. The classical capstan equation gives the limiting equilibrium for a thin flexible rope with constant Coulomb friction. At zero friction, both ends carry 150 N for every wrap setting.

For an angle `φ` measured from the load end in radians, the limiting tension is `150 × exp(−μ φ)`. The artwork spaces windings by one rope diameter to make each turn visible. Plan view shows where the line enters and leaves the drum. The classical calculation uses the cylindrical wrap angle and assumes negligible axial pitch, bending stiffness, deformation, and changing friction.
