# The Fourier Organ

Add odd harmonics to a 174 Hz fundamental. The brass pipes represent the active partials. The waveform on the instrument is the exact sum, and the optional audio plays the same coefficients at their actual frequency.

For a unit square wave the odd harmonic amplitudes are 4/(πn). All even terms vanish. A finite number of terms retains a rounded transition and ripples near its edges. The pipes have illustrative lengths. The sound uses additive synthesis in the browser.
