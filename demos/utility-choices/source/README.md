# Utility Choices

Entry 166 in Scott Campbell’s Margo exhibit brief. Change the orchard’s weather or change one villager’s needs. The winning score comes from the current priorities and the walking distance to an available place. A successful decision reserves a free slot, so visitors can see when the nearer spring is full and the orchard cistern becomes useful. A hotter afternoon immediately raises thirst and makes it grow more quickly. Existing use is allowed to finish. Reset restores the original people and needs.

The actual Margo behavior package evaluates normalized curves, combines considerations, and chooses the winning action. Margo SmartObjects exposes live offers and acquires one claim per arriving person. Claim completion releases the slot and lowers the advertised need. The scene displays the same model via Margo WebGPU and direct WebGL2. The three enamel markers identify the residents on the original painted village model. The pale line is the selected resident’s actual route through the orchard paths.
