Game UI drawn in the engine

@margoengine/ui · A title menu, a HUD with a health bar and an inventory, a pause menu, settings and dialogs, all drawn on the canvas, so they work in fullscreen and in an exported game. Use the mouse or touch, the arrow keys with Enter and Esc, or a gamepad. Settings change the theme (including high contrast) and the text size; screen readers read the same interface from a hidden DOM mirror.

D take damage · F find an item · Esc pause · arrows, Tab, Enter and the d-pad move through the interface.
