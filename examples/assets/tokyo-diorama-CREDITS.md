# Tokyo corner diorama

Original work made for Margo Engine and released under the repository's MIT license.
Generated by `examples/assets/source/tokyo_diorama/build.py` (Blender 5.3, `npm run build:tokyo`);
`source/tokyo-diorama.blend` is the saved result.

## Third-party material baked into the textures

- Surface textures from [Poly Haven](https://polyhaven.com) (CC0): green_metal_rust, rusty_painted_metal, metal_plate,
  rust_coarse_01, beige_wall_001, grey_plaster_02, blue_plaster_weathered, damaged_plaster, brick_wall_02,
  japanese_cedar_planks, hinoki_planks, dark_planks, grey_roof_tiles, clay_roof_tiles_02, asphalt_02, concrete_tiles,
  rusty_corrugated_iron, concrete_wall_004. The build downloads them into a git-ignored cache.
- Sign and road lettering set in Noto Sans CJK (SIL Open Font License 1.1), the copy bundled with Blender.

## Inspiration

The genre and presentation (a dense, stylised street-corner diorama with keyframed motion) are inspired by the
three.js `webgl_animation_keyframes` example, which shows *Littlest Tokyo* by Glen Fox (CC-BY 4.0,
https://www.artstation.com/artwork/1AGwX). No geometry, textures, signage, characters or layout from that work are used.
