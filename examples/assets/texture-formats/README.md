# Texture-format fixtures

Generated by `packages/decoders/scripts/texture-fixtures.mjs` with the decoders' own test encoders
(`packages/decoders/tests/support/texture-encoders.js`). They are our own work, so no licence notice is needed.
Regenerate them with `node packages/decoders/scripts/texture-fixtures.mjs` after building `packages/decoders`; the
script reads every file back with the readers before writing it.

Each file is a 64x64 checkerboard of 8-texel squares in its own two colours:

| File | Reader | Encoding | Colours |
| --- | --- | --- | --- |
| `checker.tga` | `@margoengine/decoders/tga` | RLE true colour (type 10), 24-bit, bottom-up rows | red and white |
| `checker-lzw.tif` | `@margoengine/decoders/tiff` | 8-bit RGB, LZW with Predictor 2, 8-row strips | green and black |
| `checker.ktx` | `@margoengine/decoders/ktx` | KTX 1, RGBA8 with the full mip chain to 1x1 | blue and yellow |
| `checker-bc1.dds` | `@margoengine/decoders/dds` | BC1 (DXT1), one level | magenta and cyan |
| `checker-rgba.dds` | `@margoengine/decoders/dds` | uncompressed RGBA8 (A8B8G8R8 masks), one level | orange and purple |
