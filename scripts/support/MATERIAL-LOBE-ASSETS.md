# Complete material-lobe fixtures

`materials-lobe-assets.js` downloads unchanged Khronos glTF Sample Assets at
commit `edc7c9e67c639d230715049ee31f9a96a6babbbe`. It checks the exact byte count
and SHA-256 before caching each file under `test-results/`. The complete assets
exercise `loadGLTF()`, explicit material installation, rendering, neutral controls,
device restoration, decoder termination, and GPU resource cleanup.
