# Cornell box numerical reference

Source: Cornell University, Computer Graphics Data,
https://bowers.cornell.edu/computer-graphics/data (accessed 2026-11-08).

The Cornell geometry coordinates, measured reflectance values and four emission knots in
`../scripts/cornell-box.mjs` are transcribed numerical facts from the published specification.
The page describes specifications and resources for public use; no separate SPDX licence is stated.
No renderer code, implementation files or photographs are included. The measurement scripts and
modified parallelogram scene are Margo-authored and excluded from package tarballs.
