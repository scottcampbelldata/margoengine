# Ocean observation

`46042-20230101.txt` retains the two original headers and first observation of
NOAA NDBC station 46042's 2023 standard meteorological archive. Source:
<https://www.ndbc.noaa.gov/view_text_file.php?filename=46042h2023.txt.gz&dir=data/historical/stdmet/>.
Retrieved 2026-11-09. NOAA/NWS US government data, public domain under
<https://www.weather.gov/disclaimer> (no third-party notice on this file).
The GPU demonstration uses its 17.2 m/s wind from 314 degrees true, converted
to a travel vector with X east and Z north. Fetch is an explicitly authored
100 km scenario, not a measurement. Wave values of 99/999 are missing values
and are not used. This is a real wind forcing example, not a hindcast or a
validation against buoy wave heights.
