# @margoengine/usdz

Optional static USDA, USDC and USDZ ingestion into `@margoengine/gltf-pro`. Core and the stage facade are unchanged. All parsing is native, with no three.js code: USDA layers go through the USDA reader shared with `@margoengine/loaders` (`readUSDA`), USDC layers through this package's Crate reader (TOC, tokens, strings, fields, field sets, paths and specs; chunked LZ4 blocks; Usd integer coding; compressed int and float arrays; list ops), and USDZ archives through the bounded ZIP reader from `@margoengine/loaders`. No external CAD runtime.

```ts
import {Engine} from '@margoengine/core';
import {loadUSDZ} from '@margoengine/usdz';

const canvas=document.createElement('canvas');document.body.append(canvas);
const engine=await Engine.create(canvas,{backend:'webgpu',capacity:10000});
const model=await loadUSDZ(engine,'/model.usdz');
engine.start();
// model.destroy() detaches its PBR plugin and frees meshes/textures.
```

`parseUSDA(textOrBytes)`, `parseUSDC(bytes)`, and async `parseUSDZ(bytes)` return a `USDAsset` with typed mesh streams, a glTF document/buffers, and async `create(engine)` to attach PBR rendering. `loadUSDZ` fetches with streaming byte bounds and creates the model. Options: `maxBytes`, `maxVertices`, `maxTriangles`, `maxDepth`, `signal`. Defaults: 64 MiB, one million expanded vertices/triangles, depth 32. The engine needs capacity for the hierarchy plus the PBR model root. Texture ownership passes to the PBR model and is released on destruction or failed setup.

`asset.images()` decodes the textures alone (what `create` uses). `@margoengine/usdz/worker` exports `loadUSDZInWorker(engine, url, options)` and `parseUSDInWorker(engine, input, options)` (USDZ, USDC or USDA, chosen by content): archive, USD parsing, texture decoding and packing, and gltf-pro's accessor/vertex step run in a worker (`dist/workers/usdz.js`, 25.9 kB gzip, loaded only by apps that import `/worker`); buffers and bitmaps are transferred back and the main thread builds the model. Same model as the main-thread path, byte for byte (`tests/worker.test.js`); falls back to the calling thread without `Worker`.

Supports stored and Deflate ZIP entries with CRC checks, static ASCII/binary hierarchies, Y/Z up and authored units, ordered translate/scale/rotateXYZ/affine transforms, triangles and convex planar polygons, left-handed winding, authored normals and vertex/face-varying UVs including indices, inherited material bindings, and constant UsdPreviewSurface diffuse/roughness/metallic factors. UsdUVTexture diffuse and normal maps are decoded from the archive. Separate roughness and metallic maps are packed into glTF's green/blue channels during creation.

Standard USDZ is an uncompressed, aligned archive. Deflate support accepts a broader ZIP envelope for interoperability. Stored entries reuse archive views. Decompression, Crate decoding, topology expansion, texture packing and GPU upload require allocations: this is **not** end-to-end zero-copy. Geometry conversion writes flat typed arrays without allocating an object per output vertex; metadata and hierarchy objects remain necessary.

Crate versions 0.4 to 0.12 are read. Dictionaries (for example `customLayerData`) and other metadata the mesh path does not use are skipped; `over` and `class` prims are ignored with their subtrees, and `active = false` prims are dropped in both formats. This is a static mesh subset. Composition/references/payloads, animation, subdivision/hole faces, concave polygons and reset transform stacks are unsupported. General shader graphs and arbitrary USD schemas are outside scope. Physical Apple AR Quick Look round trips are untested.

`npm run modern:test:usdz` checks USDA/USDC equivalence on the OpenUSD-written crate and on a test-written crate that exercises LZ4 matches and chunks, integer coding, float lookup tables, list ops and half values, ZIP/Deflate, CRC, topology, aborts and bounds. `npm run modern:test:usdz:browser` then verifies texture-channel packing, actual WebGPU pixels, bitmap cleanup and the file-picker demo. The synthetic crate fixture was generated by OpenUSD 26.08 from the checked-in USDA; `tests/generate-fixture.py` regenerates it when OpenUSD is installed. OpenUSD is not a runtime dependency.

Build with `npm run build:packages`. Run `npx vite --host 127.0.0.1` at the root and open `/examples/usdz-loader/` for the file demo. Peer ranges accept core/gltf-pro 0.1.x and 1.x while the repository remains on 0.1.0. MIT license.

Bundle size (minified + gzip, `@margoengine/*` external): 13.7 kB with the bundled three.js parsers before, 8.7 kB now; 16.1 kB before and 12.6 kB now including the tree-shaken parts of `@margoengine/loaders`.
