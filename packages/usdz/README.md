# @margoengine/usdz

Optional static USDA, USDC and USDZ ingestion into `@margoengine/gltf-pro`. Core and the stage facade are unchanged. The package uses Margo's shared bounded USDA tokenizer and ZIP reader, plus its native Crate decoder for USDC. Building and using it requires no Three.js dependency, renderer or external CAD runtime.

USDZ remains an ancillary format outside the six core launch packages and is not a core launch blocker. The historical upstream parser sources in `src/vendor/` remain reference material and are not imported or bundled.

```ts
import {Engine} from '@margoengine/core';
import {loadUSDZ} from '@margoengine/usdz';

const canvas=document.createElement('canvas');document.body.append(canvas);
const engine=await Engine.create(canvas,{backend:'webgpu',capacity:10000});
const model=await loadUSDZ(engine,'/model.usdz');
engine.start();
// model.destroy() detaches its PBR plugin and frees meshes/textures.
```

`parseUSDA(textOrBytes)`, `parseUSDC(bytes)`, and async `parseUSDZ(bytes)` return a `USDAsset` with typed mesh streams, a glTF document/buffers, and async `create(engine)` to attach PBR rendering. `loadUSDZ` fetches with streaming byte bounds and creates the model. Options: `maxBytes`, `maxVertices`, `maxTriangles`, `maxDepth`, `signal`. Defaults: 64 MiB, one million expanded vertices/triangles, depth 32. The engine grows its store when the hierarchy plus the PBR model root exceed the initial capacity. Texture ownership passes to the PBR model and is released on destruction or failed setup.

Supports stored and Deflate ZIP entries with CRC checks, static ASCII/binary hierarchies, Y/Z up and authored units, ordered translate/scale/rotateXYZ/affine transforms, triangles and convex planar polygons, left-handed winding, authored normals and vertex/face-varying UVs including indices, inherited material bindings, and constant UsdPreviewSurface diffuse/roughness/metallic factors. UsdUVTexture diffuse and normal maps are decoded from the archive. Separate roughness and metallic maps are packed into glTF's green/blue channels during creation.

Standard USDZ is an uncompressed, aligned archive. Deflate support accepts a broader ZIP envelope for interoperability. Stored entries reuse archive views. Decompression, Crate decoding, topology expansion, texture packing and GPU upload require allocations: this is **not** end-to-end zero-copy. Geometry conversion writes flat typed arrays without allocating an object per output vertex; metadata and hierarchy objects remain necessary.

This is a static mesh subset. Composition/references/payloads, animation, subdivision/hole faces, concave polygons and reset transform stacks are unsupported. General shader graphs and arbitrary USD schemas are outside scope. Physical Apple AR Quick Look round trips are untested.

`npm run modern:test:usdz` checks synthetic USDA/USDC equivalence, ZIP/Deflate, CRC, topology, aborts and bounds. `npm run modern:test:usdz:browser` then verifies texture-channel packing, actual WebGPU pixels, bitmap cleanup and the file-picker demo. The synthetic crate fixture was generated by OpenUSD 26.08 from the checked-in USDA; `tests/generate-fixture.py` regenerates it when OpenUSD is installed. OpenUSD is not a runtime dependency.

Build the workspace independently with `npm run build --workspace @margoengine/usdz`, or build all packages with `npm run build:packages`. Both paths use the checked-in parsers without an installed `three` or `@types/three`. Run `npx vite --host 127.0.0.1` at the root and open `/examples/usdz-loader/` for the file demo. Peer ranges target core/gltf-pro 1.x. MIT licensed.
